# Contributing to WDE

Thank you for contributing to Wicofe Desktop Environment.

## Requirements

- Keep changes focused and documented.
- Preserve the modular crate boundaries.
- Run the Rust formatting, check, test, and Clippy commands in [docs/development.md](docs/development.md).
- Review the complete dependency tree and license terms before adding dependencies.
- Do not submit copied source code from XFCE or another desktop environment.

## Licensing

By contributing, you agree that your contributions to WDE are provided under the repository's MPL-2.0 license, subject to applicable law and the project's contribution process.

Include the MPL-2.0 source notice in new source files where practical.
